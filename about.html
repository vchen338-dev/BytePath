About BytePath

BytePath is a free guide for people learning IT, computer science and information systems. It does not host courses. It puts the best existing ones in a sensible order.

How we choose what to include

  1. Free to start. If a resource has a paid tier, we say so.
  2. Hands-on. Every track ends with something you build or break yourself.
  3. Maintained. We prefer official documentation and sources that are kept up to date.
  4. Honest about scope. A beginner track should not need three other tracks first.
  5. Clear about subject. Each track is tagged IT, computer science, information systems or a mix, so you can see where it fits.
