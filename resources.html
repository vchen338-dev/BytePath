Frequently asked questions

Do I need a degree to work in IT?

No. Many IT support, networking and cloud roles hire on skills, certifications and proof of practice. Some employers still prefer a degree, so check the postings for the jobs you want.

How many hours a week should I study?

Five to eight hours is realistic alongside work or school. Short, regular sessions beat one long weekend push.

Which track should I take first?

For IT, start with networking and Linux. For computer science, start with programming fundamentals and discrete math. Later tracks assume you know these.

Should I study IT or computer science?

Choose IT if you want to set up, run and protect systems, and computer science if you want to design software and understand why it works. The skills overlap, so you can start with one and add the other. Tracks tagged with both subjects are good bridges.

Do I need strong math for computer science?

You need comfortable high-school algebra to begin. The discrete math track builds the rest as you go. Theory and machine learning tracks use more math, so take them later.

Do I need to buy equipment?

No. A laptop with 8 GB of RAM or more can run virtual machines using free tools such as VirtualBox. Cloud providers also offer free tiers for practice.

Are these resources really free?

All of them have free content you can start with. Some, such as certification exams and a few course platforms, charge for extras. We say so when it applies.
